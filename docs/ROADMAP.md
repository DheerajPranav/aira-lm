# Roadmap

## Phase 0 — Decision foundation

Mission, invariants, threat model, data classification, ADRs and evaluation plan.

## Phase 1 — Robust memory core

Schema, lifecycle, guard, audit, local storage, deterministic evaluator.

## Phase 2 — Retrieval and composition

FTS5/BM25, ranking, context budgets, debug explanations.

## Phase 3 — Integrated local assistant

Mock backend, CLI, graceful degradation, inspect/correct/forget/export.

## Phase 4 — Memory evaluation

Golden and adversarial benchmark, regression gates, local metrics.

## Phase 5 — Aira Core

Byte tokenizer, tiny transformer, generation and checkpointing.

## Phase 6 — Training and ablations

Local corpus training, memory-conditioned evaluation, baseline comparisons.

## Phase 7 — Hardened local release

Packaging, migrations, recovery, documentation, model card and reproducible release checks.

## Deferred scale phase

PostgreSQL, row-level security, vector retrieval, Redis, queues, tracing exporters and hosted deployment only when measured local constraints justify them.
