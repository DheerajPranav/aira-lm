# Branding

## Name

**Aira LM**

## Tagline

**Small model. Long memory. Gentle by design.**

## Technical tagline

**Remember what matters. Forget responsibly.**

## Origin statement

Aira was inspired by the quiet strength of elephants and their association with enduring memory. The project investigates how a compact model can remember what matters without carrying everything forever.

## Component names

- Aira Core — language model
- Aira Recall — retrieval and ranking
- Aira Vault — durable storage
- Aira Trail — provenance and audit
- Aira Guard — memory safety and privacy
- Aira Fade — decay and archival
- Aira Bench — evaluation
- Aira Herd — possible future graph or related-memory grouping

## Visual concept

A minimal elephant assembled from token blocks and memory nodes:

- body: token blocks
- ears: attention arcs
- head: clustered memory nodes
- trunk: retrieval path
- one illuminated node: a retained important memory

Avoid realistic wildlife imagery, robot heads and brain icons.

## Palette

- Elephant Slate: `#111318`
- Soft Stone: `#C8C5BC`
- Memory Green: `#75A478`
- Warm Rose: `#A76E78`

The warm rose can remain a quiet personal accent without requiring a public explanation.
